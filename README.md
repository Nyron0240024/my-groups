# My Groups — приложение преподавателя

PWA для учёта групп, учеников, домашних заданий и отметок выполнения. Интерфейс без регистрации: приложение создаёт анонимную Supabase-сессию. Данные хранятся в облачной базе Supabase.

## Что реализовано
- Группы и ученики
- Домашние задания с названием, описанием и датой урока
- Для каждого ученика по каждому заданию: `＋` (сделал) / `−` (не сделал)
- История заданий по датам
- Установка на телефон как PWA

## Важное ограничение первой версии
Анонимная сессия сохраняется в браузере/на установленном приложении. Если очистить данные браузера, потерять телефон или перейти на другое устройство, восстановить анонимную сессию автоматически нельзя. Не очищайте данные браузера и пока не используйте приложение как единственную копию важных данных. Код восстановления между телефонами в этой сборке ещё не реализован — для него нужен отдельный защищённый серверный механизм. Это не то же самое, что обычный экспорт данных.

## Настройка облака (один раз)
1. Откройте https://supabase.com и создайте проект.
2. В проекте откройте SQL Editor → New query.
3. Скопируйте весь файл `supabase-schema.sql` и нажмите Run.
4. Откройте Authentication → Providers (или Sign In / Providers) и включите Anonymous Sign-Ins.
5. Откройте Project Settings → API. Скопируйте Project URL и `anon` / publishable key.
6. В `index.html` найдите:
   - `YOUR_SUPABASE_URL` и замените на Project URL.
   - `YOUR_SUPABASE_ANON_KEY` и замените на anon/publishable key.
   Ключ `service_role` никогда не вставляйте в сайт и никому не отправляйте.

## Публикация
Загрузите все файлы этой папки в GitHub-репозиторий. Для GitHub Pages:
- Settings → Pages
- Deploy from a branch
- выберите `main` и `/ (root)`, Save
- откройте появившийся адрес `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

Открыть сайт на телефоне:
- Android: Chrome → меню ⋮ → Add to Home screen / Install app.
- iPhone: Safari → Поделиться → На экран «Домой».

## Примечания
- Для синхронизации нужен интернет; PWA оболочка кэшируется, но добавление/изменение данных офлайн пока не поддерживается.
- Не публикуйте anon key вместе с секретными ключами. Anon/publishable key предназначен для клиентского приложения; безопасность обеспечивают RLS-политики из SQL.
